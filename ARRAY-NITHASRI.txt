🧩 1. Normal Array in Java — Detailed Explanation


---

💡 Definition

An array in Java is a collection of similar data types stored in contiguous memory locations.
It’s a fixed-size, index-based data structure that allows you to store multiple elements under a single variable name.


---

🧠 Key Characteristics

Feature	Description

Type Homogeneity	All elements in an array must be of the same data type (e.g., all int, all String).
Fixed Size	Once created, the size of an array cannot change (unlike an ArrayList).
Indexed Access	Each element is accessed using its index, starting from 0.
Stored in Heap Memory	Arrays in Java are objects, and they are allocated in heap memory.
Length Property	The property .length gives the total size of the array.
Random Access	You can directly access any element using its index — in O(1) time.



---

⚙ Array Declaration, Creation, and Initialization

There are three steps to create and use an array in Java.

1️⃣ Declaration

You declare the type of elements and use [] to denote an array.

int[] numbers;         // preferred style
// OR
int numbers[];         // valid but less common

2️⃣ Creation

You allocate memory for the array using the new keyword.

numbers = new int[5];  // creates an array of 5 integers

3️⃣ Initialization

You assign values to each index.

numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;
numbers[3] = 40;
numbers[4] = 50;


---

💻 Complete Example

public class NormalArrayExample {
    public static void main(String[] args) {
        // Step 1: Declare and create an array
        int[] numbers = new int[5];

        // Step 2: Initialize array elements
        numbers[0] = 10;
        numbers[1] = 20;
        numbers[2] = 30;
        numbers[3] = 40;
        numbers[4] = 50;

        // Step 3: Access and print array elements
        for (int i = 0; i < numbers.length; i++) {
            System.out.println("Element at index " + i + ": " + numbers[i]);
        }
    }
}

Output:

Element at index 0: 10
Element at index 1: 20
Element at index 2: 30
Element at index 3: 40
Element at index 4: 50


---

📦 Array Initialization Shortcut

You can also initialize an array directly when you declare it.

int[] numbers = {10, 20, 30, 40, 50};

Here:

The array size is automatically determined by the number of elements.



---

🧮 Accessing Elements

You use the index to access elements:

System.out.println(numbers[2]); // Output: 30

If you access an invalid index, you’ll get:

Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException


---

⚙ Array Length

Each array object has a public instance variable called length that stores the number of elements.

System.out.println("Array length: " + numbers.length);


---

🔁 Traversing an Array

There are multiple ways to loop through arrays.

1️⃣ Using for loop

for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}

2️⃣ Using for-each loop

for (int num : numbers) {
    System.out.println(num);
}


---

🧩 Arrays with Other Data Types

Example: String Array

String[] fruits = {"Apple", "Banana", "Mango", "Cherry"};

for (String fruit : fruits) {
    System.out.println(fruit);
}

Example: Double Array

double[] prices = {10.5, 20.0, 30.75};

for (double price : prices) {
    System.out.println(price);
}




Dynamic Array in Java — In Detail


---

💡 Definition

A dynamic array is a data structure that can grow and shrink automatically during runtime as elements are added or removed.

Unlike a normal (static) array, which has a fixed size, a dynamic array resizes itself when needed.

In Java, you can either:

Implement your own dynamic array, or

Use Java’s built-in ArrayList (which is a dynamic array under the hood).



---

🧠 1️⃣ Why We Need Dynamic Arrays

Let’s start with a problem:

int[] arr = new int[3];
arr[0] = 10;
arr[1] = 20;
arr[2] = 30;
// Now, what if you want to add arr[3] = 40?

You can’t — because normal arrays in Java have fixed length.
To “add more elements,” you would have to:

1. Create a new array with larger size.


2. Copy all existing elements into it.


3. Add the new element.



This is tedious to do manually every time.
👉 A Dynamic Array solves this automatically.


---

⚙ 2️⃣ How a Dynamic Array Works

A dynamic array manages two key things internally:

Property	Description

Capacity	Total space currently allocated in memory.
Size	Number of elements currently stored.


When the array becomes full:

It creates a new array with double the capacity.

Copies all old elements into the new array.

Adds the new element.


This resizing gives flexibility at runtime.


---

🧮 Example of Resizing Mechanism

Step	Size	Capacity	Action

Create new array	0	2	Allocate initial array
Add element 1	1	2	Stored
Add element 2	2	2	Array is now full
Add element 3	3	4	Double the capacity to 4
Add element 4	4	4	Stored
Add element 5	5	8	Double capacity again



---

💻 3️⃣ Implementing a Dynamic Array (Custom Example)

Here’s a simple custom implementation of a dynamic array in Java.

import java.util.Arrays;

public class DynamicArray {
    private int[] array;  // underlying storage
    private int size;     // number of elements currently in array

    // Constructor — start with small capacity
    public DynamicArray() {
        array = new int[2];
        size = 0;
    }

    // Add element
    public void add(int element) {
        if (size == array.length) {
            resize();  // grow array when full
        }
        array[size++] = element;
    }

    // Get element by index
    public int get(int index) {
        if (index < 0 || index >= size)
            throw new IndexOutOfBoundsException("Index out of range");
        return array[index];
    }

    // Resize method (double capacity)
    private void resize() {
        int newCapacity = array.length * 2;
        array = Arrays.copyOf(array, newCapacity);
    }

    // Return current size
    public int size() {
        return size;
    }

    // Print elements
    public void display() {
        for (int i = 0; i < size; i++) {
            System.out.print(array[i] + " ");
        }
        System.out.println();
    }

    // Main method
    public static void main(String[] args) {
        DynamicArray da = new DynamicArray();
        da.add(10);
        da.add(20);
        da.add(30); // triggers resize
        da.add(40);

        System.out.println("Array elements: ");
        da.display();

        System.out.println("Size: " + da.size());
        System.out.println("Element at index 2: " + da.get(2));
    }
}

Output:

Array elements:
10 20 30 40 
Size: 4
Element at index 2: 30

What is Generic in Java?

Generics mean writing code that can work with any data type —
but still type-safe (so you don’t mix types by mistake).


---

💬 Simple Way to Explain to Friends:

> “Generics allow us to write one class or method that can handle different types of data — like Integer, String, or Double — without rewriting the same code again and again.”




---

🧩 Example Without Generics

ArrayList list = new ArrayList();
list.add("Hello");
list.add(10); // 😬 allowed, but risky

You can add anything — but when you try to take it out, you might get a runtime error.


---

✅ Example With Generics

ArrayList<String> list = new ArrayList<>();
list.add("Hello");
// list.add(10); // ❌ Error: can’t add integer to string list

Now the compiler checks types for you —
that’s type safety ✅.


---

🪄 How It Works (Simple Version)

<T> means “any type”.

You decide what T is when you create the object.


Example:

class Box<T> {
    T value;
    void set(T value) { this.value = value; }
    T get() { return value; }
}

Usage:

Box<Integer> b1 = new Box<>();
Box<String> b2 = new Box<>();

Here:

T becomes Integer in b1

T becomes String in b2


So the same Box class works for any type. 🎯


---

🔹 One-Line Summary to Tell Your Friends:

> “Generics in Java let us make reusable, type-safe classes and methods that can work with any data type.”



---
// A simple generic class
class Box<T> {
    private T value; // T means any type (like Integer, String, etc.)

    void setValue(T value) {
        this.value = value;
    }

    T getValue() {
        return value;
    }
}

public class Main {
    public static void main(String[] args) {
        // Box for Integer
        Box<Integer> intBox = new Box<>();
        intBox.setValue(100);

        // Box for String
        Box<String> strBox = new Box<>();
        strBox.setValue("Hello Generics");

        System.out.println("Integer Box Value: " + intBox.getValue());
        System.out.println("String Box Value: " + strBox.getValue());
    }
}
